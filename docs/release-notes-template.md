## Installing

See the [install guide](https://github.com/RavindraDave/postloom/blob/main/docs/install.md).
The Mac and Windows downloads here are not signed by Apple or Microsoft, so
your computer asks you to confirm the first time you open Postloom; the guide
shows how. On Windows, the Microsoft Store version installs without any warning.

Each download has a `.sha256` file to check it arrived intact.
