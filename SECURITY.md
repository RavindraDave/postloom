# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report privately via GitHub's **"Report a vulnerability"** (Security → Advisories) on this repository. Include steps to reproduce, affected version and OS, and impact.

You can expect an acknowledgement within 5 working days and a status update within 14 days. We'll credit reporters in the release notes unless you prefer otherwise.

## Supported versions

Postloom has not been released yet. Once released, the latest minor version receives security fixes.
